# 🏠 Welcome

MoonBD is a refined Black Desert private server built around fast progression, modernized combat, and high-end content accessibility. The server now runs on the latest client version featuring the release of the Woosa, Maegu, and Drakania classes alongside updated combat systems and 2023 class balance changes.

MoonBD focuses on reducing unnecessary grind while preserving meaningful progression, competitive PvP, and long-term gearing systems. Players begin fully prepared to experience all major content immediately.
