# 🛠️ Life Tools

### Overview

**Manos Life Tools** are specialized lifeskilling tools designed to increase various life mastery stats and processing capabilities.

---

### Manos Life Tools Directory

* [**Manos Flask**](https://moonbd.online/codex/item//705548)
  * Overview: Increases gathering and processing masteries.
  * Codex Links: [**Manos Flask**](https://moonbd.online/codex/item//705548) | [**Manos Stone**](https://moonbd.online/codex/?q=Manos+Stone&lim=25)
* [**Manos Ladle**](https://moonbd.online/codex/item//705545)
  * Overview: Increases cooking masteries.
  * Codex Links: [**Manos Ladle**](https://moonbd.online/codex/item//705545) | [**Manos Stone**](https://moonbd.online/codex/?q=Manos+Stone&lim=25)
* [**Manos Hunting Bag**](https://moonbd.online/codex/item//705542)
  * Overview: Increases hunting masteries. The deprecated and disabled **Huntress Bow** is replaced with standard Matchlocks, and its hunting stats are moved to the [**Manos Hunting Bag**](https://moonbd.online/codex/item//705542). The bag starts with stats equivalent to +15 and matches the PEN Huntress Bow at PEN +20.
  * Codex Links: [**Manos Hunting Bag**](https://moonbd.online/codex/item//705542) | [**Manos Stone**](https://moonbd.online/codex/?q=Manos+Stone&lim=25)
* [**Manos Sailing Log**](https://moonbd.online/codex/item//760943)
  * Overview: Increases sailing masteries.
  * Codex Links: [**Manos Sailing Log**](https://moonbd.online/codex/item//760943) | [**Manos Stone**](https://moonbd.online/codex/?q=Manos+Stone&lim=25)
