# Artifact System

#### Artifact & Lightstone System Overhaul

A major update to the **Artifact and Lightstone System** has been implemented to provide greater flexibility, expanded customization, and improved integration with modern gameplay systems.

**Overview**

The redesign separates artifact set effects from their old static slots and introduces a new **Eye Slot** mechanic used exclusively for set integrations. Players must exchange outdated artifacts to reclaim their bonuses and transition to the new system format.

**Artifact Set Effect Changes**

All existing artifacts with set effects are now deprecated and have been removed from the standard loot pool. These legacy artifacts are now unusable and cannot apply old set bonuses.

**Action Required**

Players must visit the NPC [**Dalishain**](https://moonbd.online/codex/?q=Dalishain&lim=50&t=npcs) to exchange old artifacts. Doing so restores the appropriate set effect or provides the updated equivalent within the new **Eye Slot** system.

**New Eye Slot Integration**

Set effects are no longer restricted to normal artifact gear slots. All artifact set effects are now equipped through the **Eye Slot** interface. This allows players to freely combine setups without replacing existing gear pieces. **Eye Slots** can be customized for different artifact loadouts or playstyles.

**Lightstone System Expansion**

The **Lightstone System** has been expanded to allow additional crystal infusions and synergy options.

* **New Features**: **Earring Artifacts** and **Mouth Artifacts** now accept **Lightstones** as crystals.
* **Additional Infusion Slots**: A total of four slots are available:
  * 2x **Right Lightstone Slots**
  * 2x **Left Lightstone Slots**

This addition significantly improves build diversification and stat optimization, giving players more freedom to mix offensive and defensive **Lightstones** across gear setups.

**Dalishain Exchange**

The NPC [**Dalishain**](https://moonbd.online/codex/?q=Dalishain&lim=50&t=npcs) handles all conversions related to legacy artifact items. Players can visit the NPC [**Dalishain**](https://moonbd.online/codex/?q=Dalishain&lim=50&t=npcs) to:

* Exchanging obsolete set-effect artifacts.
* Receiving new **Eye Slot**-compatible equivalents or updated versions.
* Managing any leftover materials linked to the transition.

> \[!IMPORTANT] Any player still holding a pre-overhaul artifact must perform this exchange to retain functionality. Unexchanged artifacts will remain cosmetic or non-functional.

This overhaul standardizes artifact progression, increases customization variety, and ensures the system will scale efficiently with future expansions.

***

#### System Mechanics & Lightstone Infusion

The updated system separates set bonuses from raw stats and follows a two-part process:

**Part 1: Crafting the Lightstone Set Item**

1. The Processing menu is opened by pressing `L` and selecting **Manufacture**.
2. Four individual **Lightstones** are placed into the **Manufacture** slots.
3. The processing is started to combine the individual pieces into one standalone **Set Item**.
4. Once crafted, this standalone **Set Item** can be equipped or used separately from **Artifacts**, slotted into the special **Eye Slot** interface in the user interface to gain permanent bonuses.

**Part 2: Artifact Transfusion**

1. The inventory is opened, and the two **Artifacts** (specifically **Earring Artifacts** and **Mouth Artifacts**) are equipped.
2. The **Transfusion** menu is opened.
3. Up to two additional **Lightstones** can be slotted into each equipped **Artifact** as crystals (totaling four slots: two **Right Lightstone Slots** and two **Left Lightstone Slots**).
4. This configuration allows the custom **Set Item** to be equipped in the **Eye Slot** while simultaneously running four extra **Lightstones** (two per **Artifact**) for maximum stat optimization.
