# 🟪 Alchemy System

## Alchemy Enhancement Update

This page contains the latest **Alchemy Stone enhancement rates** and details about the required enchant item.

### Enchant Item

[**Stone of Alchemist**](../craft-items/stone-of-alchemist.md)

#### Enhancement Changes

Alchemy Stones **no longer break or downgrade** when enhancement fails.\
All enhancement attempts are now **risk-free**.

#### Material Requirements

The required materials for Alchemy Stone enhancement have been updated as follows:

| Enhancement Stage      | Required Materials |
| ---------------------- | ------------------ |
| Rough → Sturdy         | 1x                 |
| Sharp → Resplendent    | 5x                 |
| Resplendent → Splendid | 15x                |
| Splendid → Shining     | 30x                |

The enhancement success rates for Alchemy Stones have been updated as follows:

| Tier        | New Rate |
| ----------- | -------- |
| Sharp       | 50%      |
| Resplendent | 15%      |
| Splendid    | 3%       |
| Shining     | 1%       |
