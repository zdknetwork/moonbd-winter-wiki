# Artifact System

## **Artifact & Lightstone System Overhaul**

A major update to the **Artifact and Lightstone** system has been implemented to provide greater flexibility, expanded customization, and improved integration with modern gameplay systems.

***

### **Overview**

The redesign separates artifact set effects from their old static slots and introduces a new **Eye Slot** mechanic used exclusively for set integrations.\
Players must **exchange outdated artifacts** to reclaim their bonuses and keep up with the new system format.

***

### **Artifact Set Effect Changes**

* All existing artifacts with **set effects** are now **deprecated** and have been removed from the standard loot pool.
* These legacy artifacts are now **unusable** and cannot apply old set bonuses.

#### **Action Required**

Players must visit **NPC Dalishain** to **exchange old artifacts**.\
Doing so restores the appropriate set effect or provides the updated equivalent within the new Eye Slot system.

***

### **New Eye Slot Integration**

* Set effects are no longer restricted to normal artifact gear slots.
* All artifact set effects are now equipped through the **Eye Slot** interface.
* This allows players to freely combine setups without replacing existing gear pieces.
* Eye slots can be customized for different artifact loadouts or playstyles.

***

### **Lightstone System Expansion**

The Lightstone system has been expanded to allow **additional crystal infusions** and synergy options.

#### **New Features**

* **Earring and Mouth Artifacts** now accept Lightstones as **crystals**.
* Additional infusion slots are available:
  * **2 Right Lightstone Slots**
  * **2 Left Lightstone Slots**

This addition significantly improves build diversification and stat optimization, giving players more freedom to mix offensive and defensive Lightstones across gear setups.

***

### **Dalishain Exchange**

The **Dalishain NPC** now handles all conversions related to legacy artifact items.\
Players can visit Dalishain to:

* Exchange obsolete set-effect artifacts.
* Receive new Eye Slot-compatible equivalents or updated versions.
* Manage any leftover materials linked to the transition.

**Note:** Any player still holding a pre-overhaul artifact must perform this exchange to retain functionality.\
Unexchanged artifacts will remain cosmetic or useless.

***

This overhaul standardizes artifact progression, increases customization variety, and ensures the system will scale efficiently with future expansions.
