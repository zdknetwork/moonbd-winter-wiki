# Custom NPCs & Exchanges

MoonBD features several custom NPCs located in major cities, primarily Velia City. These NPCs facilitate high-end equipment progression, material conversions, failstack exchanges, and special reward redemptions.

All detailed exchange recipes, rates, and requirements are managed directly through the official MoonBD Codex search queries and NPC database pages.

---

### [**Moon Master**](https://moonbd.online/codex/npc/900994)
* **Role**: All-in-One Service NPC
* **Description**: [**Moon Master**](https://moonbd.online/codex/npc/900994) provides general utility services in major and minor cities. These services include storage access, currency exchange, skill add-on configurations, Central Market access, equipment type swaps, and basic material conversions.
* **Codex Link**: [**Moon Master**](https://moonbd.online/codex/npc/900994) database page

### [**Nemos**](https://moonbd.online/codex/npc/900995)
* **Role**: General Exchanges
* **Description**: [**Nemos**](https://moonbd.online/codex/npc/900995) specializes in crafting-related and gear exchanges, primarily facilitating the conversion of enhanced accessories (such as **Manos** and **Deboreka**) into **Preonne** and **Kharazad** accessories, as well as exchanges for **Guru** profession boxes and **La Orzeca** armor.
* **Codex Link**: [**Nemos**](https://moonbd.online/codex/npc/900995) database page

### [**Spirit**](https://moonbd.online/codex/npc/900992)
* **Role**: Failstack Exchanges
* **Description**: [**Spirit**](https://moonbd.online/codex/npc/900992) manages enhancement progression and treasure item assembly. Players can exchange materials (such as **Black Stones**, **Concentrated Gems**, and rare treasure pieces) for failstacks (**Advice of Valks**) and enhancement assistance items.
* **Codex Link**: [**Spirit**](https://moonbd.online/codex/npc/900992) database page

### [**Loyal**](https://moonbd.online/codex/npc/900993)
* **Role**: Battle Exchange NPC
* **Description**: [**Loyal**](https://moonbd.online/codex/npc/900993) manages battlefield and siege reward redemptions. Players can exchange **Red Seals** and **Resplendent Medals of Honor** for **Advice of Valks**, weapon exchange coupons, and rare crystals.
* **Codex Link**: [**Loyal**](https://moonbd.online/codex/npc/900993) database page

### [**Chaotica**](https://moonbd.online/codex/npc/900990)
* **Role**: High-End Progression Exchanges
* **Description**: [**Chaotica**](https://moonbd.online/codex/npc/900990) handles progression exchanges using **Chaotica Tokens**. These include boss items (such as **Vell's Heart** and **Garmoth's Heart**), sleeping origin armor **Flames** (**Flame of Frost**, **Flame of Resonance**, **Flame of Hongik**, **Flame of Despair**), and **Dream Horse** emblems.
* **Codex Link**: [**Chaotica**](https://moonbd.online/codex/npc/900990) database page

### [**Lux**](https://moonbd.online/codex/npc/900991)
* **Role**: Moon Coin Exchange NPC
* **Description**: [**Lux**](https://moonbd.online/codex/npc/900991) manages **Moon Coin** exchanges. Players can exchange **Moon Coins** for premium perks (such as **MoonBD Premium** time), pets, mounts, ship registrations, and custom titles.
* **Codex Link**: [**Lux**](https://moonbd.online/codex/npc/900991) database page

### [**Riona**](https://moonbd.online/codex/npc/900996)
* **Role**: Event Exchange NPC
* **Description**: [**Riona**](https://moonbd.online/codex/npc/900996) handles event-specific item redemptions. These exchanges are only active during server event periods.
* **Codex Link**: [**Riona**](https://moonbd.online/codex/npc/900996) database page

### [**Minotavros**](https://moonbd.online/codex/npc/901009)
* **Role**: Weapons & Matchlock Exchange
* **Description**: [**Minotavros**](https://moonbd.online/codex/npc/901009) manages matchlock exchanges and equipment conversions for new classes.
* **Codex Link**: [**Minotavros**](https://moonbd.online/codex/npc/901009) database page

### [**Neohun**](https://moonbd.online/codex/?q=Neohun&lim=50&t=npcs)
* **Role**: Fallen Exchange NPC
* **Description**: [**Neohun**](https://moonbd.online/codex/?q=Neohun&lim=50&t=npcs) allows players to exchange **Moon Coins** for special Cash Shop outfits and event packages.
* **Codex Link**: [**Neohun**](https://moonbd.online/codex/?q=Neohun&lim=50&t=npcs) search query
