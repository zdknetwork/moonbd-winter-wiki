# Nemos Exchanges

### Overview

**Nemos** specializes in crafting-related exchanges. These include enhanced accessory conversions and Guru profession boxes.

### How to Obtain

1. Visit **Nemos** in Velia City.
2. Select the crafting or profession exchange.
