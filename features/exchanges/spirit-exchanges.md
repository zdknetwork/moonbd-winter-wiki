# Spirit Exchanges

### Overview

**Spirit** focuses on enhancement progression and treasure item exchanges. This NPC allows conversion of materials into failstacks, scrolls, and completed treasure items.

### How to Obtain

1. Speak with **Spirit** in Velia City.
2. Select the desired enhancement or treasure exchange.
