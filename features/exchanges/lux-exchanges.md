# Lux Exchanges

### Overview

**Lux** handles **Moon Coin** exchanges. These exchanges include premium benefits, pets, mounts, workers, ships, and utility items.

### How to Obtain

1. Visit **Lux** in Velia City.
2. Spend **Moon Coins** on the desired reward.
