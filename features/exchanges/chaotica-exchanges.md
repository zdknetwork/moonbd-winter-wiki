# Chaotica Exchanges

### Overview

**Chaotica** provides high-end progression exchanges. These exchanges focus on boss items, Flames, enhancement resources, and Dream horse rewards.

### How to Obtain

1. Locate **Chaotica** in Velia City.
2. Interact with the NPC.
3. Select the desired exchange from the list.
