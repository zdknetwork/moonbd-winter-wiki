# Merge Mails

#### **Merge Mails**

**Overview:**\
**Merge Mails** is a background feature that automatically combines multiple mail entries containing the same item into a single mail.\
It helps reduce mail clutter and makes it easier to manage rewards from various systems.

***

**Purpose:**\
Due to the large number of mails players can receive from features like **Redeem Codes**, **Auto Buy**, inventories may become filled with multiple mails containing identical items.\
This feature ensures that identical item mails are automatically merged to simplify management and avoid the need to manually open several duplicates.

***

**Functionality:**

* Automatically merges all mails that contain the **same item** into one mail.
* Triggered **automatically when starting the game** from the **Launcher (Play button)**.
* This feature is **not visible in the game UI** and happens silently during startup.

***

**Requirements:**

* At least **two or more mails** must contain the **same item**.
