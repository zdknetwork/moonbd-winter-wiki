# 👽 Custom World Bosses

### Overview

In addition to standard game events, MoonBD features custom world bosses that spawn periodically and offer unique progression and web shop rewards.

### World Boss Configuration

{% hint style="info" %}
Standard world bosses are removed from the game. Only enhanced world boss variants spawn on the server:
* [**Nightmarish Kzarka**](https://moonbd.online/codex/?q=Nightmarish+Kzarka&lim=50&t=npcs)
* [**Stormbringer Karanda**](https://moonbd.online/codex/?q=Stormbringer+Karanda&lim=50&t=npcs)
* [**Thundercloud Kutum**](https://moonbd.online/codex/?q=Thundercloud+Kutum&lim=50&t=npcs)
* [**Bloodstorm Nouver**](https://moonbd.online/codex/?q=Bloodstorm+Nouver&lim=50&t=npcs)
{% endhint %}
