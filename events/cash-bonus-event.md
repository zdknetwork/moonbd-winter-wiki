# 💵 Cash Bonus Event

### Overview

The **Cash Bonus Event** is an automated donation bonus system that periodically increases bonus rewards received from donations. The event activates randomly every 30 to 90 days and may also become active during special occasions, holidays, or major server celebrations.

Players are not required to manually activate the event. Any eligible donation completed during the active period automatically receives the configured bonus amount.

### How It Works

* The system activates automatically during selected event periods.
* Bonus percentages vary depending on the current event configuration.
* Donations completed while the event is active automatically receive additional bonus rewards.
* No additional registration, coupon, or activation process is required.
* Bonus rewards are delivered together with the normal donation rewards.

### Notes

* The event schedule is intentionally random to maintain limited-time availability.
* Special occasion activations may occur during holidays, anniversaries, or global server events.
* Bonus percentages may vary between events.
* The donation bonus applies only during the active event period.
* Event activation and multiplier details are usually announced through Discord or official announcements.

### Example Multipliers

| Event Type              | Bonus Reward | Active Period       |
| ----------------------- | ------------ | ------------------- |
| Standard Bonus Event    | +25%         | Random (30–90 Days) |
| Special Occasion Event  | +50%         | As Announced        |
| Major Celebration Event | +100%        | As Announced        |

### Additional Information

* Donations completed outside the active event period receive normal rewards only.
* Event bonuses apply automatically without additional steps.
* Official announcements provide exact activation dates and bonus percentages for each event.
