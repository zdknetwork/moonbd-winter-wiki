# 📶 Exitlag! Guide

### Overview

**ExitLag** is a network optimization tool that improves connection stability and reduces ping.\
The steps below outline how to properly configure ExitLag for use with **MoonBD**.

***

### Step 1: Download and Install ExitLag

* ExitLag can be downloaded from the **official website** → [https://www.exitlag.com](https://www.exitlag.com)
* The program is installed and launched, and players can create an account if needed.

***

### Step 2: Configure ExitLag

1. ExitLag is opened.
2. In the search bar, the term **"Black Desert Online"** is entered.
   * Regions labeled "JP" or "Launcher" must not be selected.
3. **"Black Desert Online"** is selected from the list.
4. The **Game Region** tab is clicked, and a routing location is selected.
   * Recommended: **DE Falkenstein** or **DE Frankfurt** (closest to the MoonBD server).
5. The **Apply Routes** button is clicked to save the settings.

***

### Step 3: Activate Connection Optimization

* The switch toggle for **ExitLag** must be set to **ON**.
* The active route is indicated when the **red dot** under the **Black Desert Online** icon is illuminated.

***

### Step 4: Launch MoonBD

1. **MoonBD** is launched normally.
2. Upon loading into the server selection screen, **ExitLag** detects network activity.
   * This connection is confirmed when **traffic indicators** begin moving in the ExitLag dashboard.

Once active, ExitLag automatically optimizes the network route for smoother gameplay and minimal packet loss.

***

### Notes

* ExitLag must be started **before launching MoonBD**.
* If servers or regions are changed, routing settings should be checked again.
* ExitLag offers a **free trial period** - no credit card required on the initial download.
